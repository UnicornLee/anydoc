## 补上 .doc 浮动图片提取 → 原生路径与 Word 基线**逐行完全一致**

新增 `src/formats/doc/shapes.rs`（`mod shapes;` 挂进 doc/mod.rs）。

**实测出的 FIB 偏移（Word 97 fibRgFcLcb 布局，与"标准表"差 6 个 index，
务必以实测为准）**：

| 结构 | FIB 偏移 | 本文实测 |
|---|---|---|
| fcClx | `0x1A2` | 已用于现有代码（可作基准锚点） |
| fcPlcspaMom / lcb | `0x1DA` / `0x1DE` | fc=0xE9E lcb=124 → n=(124-4)/30=**4** |
| fcPlcspaHdr | `0x1E2` | = 0xE9E+0x7C，正好接在 Mom 之后（互证） |
| fcDggInfo / lcb | `0x22A` / `0x22E` | fc=0xB24 lcb=890 |

**浮动图的完整数据链**（全部实证）：
`Plcspa`(cp,spid) → DggInfo 里 DgContainer/SpContainer 的 `FSP`(0xF00A).spid
→ 兄弟 `FOPT`(0xF00B) 的属性 **`pib` = opid 0x4104（&0x3FFF 后是 0x0104）**，
值即 BStore 的 **1-based** 下标 → BStore 的 `FBSE`(0xF007).**`foDelay` = u32 @body+28**
→ **blip 记录在 `WordDocument` 流**（不是 Data 流！4 个 foDelay 连续且
首尾正好填满 WordDocument 23122 字节；Data 流里那 55 个 WMF 是内联 OLE 预览图）。

**踩到的坑**：

1. 顶层 DggContainer 与后面的 DgContainer 之间有 **1 字节 padding**，严格按
   记录长度走会截断 → `walk()` 遇到非 `0xF0xx` 的 recType 就 `off += 1` 跳过。
2. `FBSE` 固定 36 字节（btWin32/btMacOS/rgbUid16/tag/size/cRef/foDelay/…），
   `size` 含 8 字节记录头；`foDelay` 指向的是**完整 blip 记录**（ver_inst=0x2160，
   instance=0x216 → 单 rgbUid，与 FBSE 的 rgbUid 相同，可用来校验）。
3. 别用 nFib 做守卫：本文 nFib=**0x00C1**（不是 0x00D9），加了
   `nFib < 0x00D9 就跳过` 直接把 4 张图全过滤掉了。现有代码本来就用 0x1A2
   读 fcClx，即已假定 Word 97 布局，不必再加版本判断。

**验证**：

  → 是真实图形不是垃圾。

## WMF→PNG 转换：GDI+ 直接播放会丢笔画，必须走 GDI

- 讲义31提取出的 `.wmf` 是**标准 WMF（无 placeable header）**。GDI+ 的
  `Metafile`+`DrawImage` 播这类文件会大面积丢内容（缺圆、缺字、比例错），
  包 placeable header、改 bbox 都无效。
- 可靠路线已固化进 `scripts/wmf-to-png.ps1`：
  `SetWinMetaFileBits`（MM_ANISOTROPIC, 5080x5080 him）→ 内存 EMF
  → `GetEnhMetaFileBits` 落临时文件 → GDI+ 300dpi 画到白底位图
  → 扫描非白像素裁剪（4% 边距）→ PNG。
- 裁剪函数 `Get-ContentBounds` 用 LockBits/Format24bppRgb 逐像素找
  任一通道 <240 的包围盒。
- PowerShell 陷阱两个：`0x9AC6CDD7` 超 Int32 不能直接 `[uint32]` 强转
  （要逐字节写）；`Add-Type -MemberDefinition` 不能有 using 且类型嵌套，
  多类型要用 `-TypeDefinition` 包 namespace。

## WMF→PNG 跨平台：Windows 仍走 GDI/GDI+，其他平台外调 LibreOffice

`src/shared/wmf.rs` 重构成两 backend + 顶层 re-export：

- **`windows_backend`**（原 GDI/GDI+ 实现，`#[cfg(windows)]`）：不变。
- **`unix_backend`**（`#[cfg(not(windows))]`）：
  - `soffice_command()` 用 `OnceLock` 缓存一次探测结果，遍历 `soffice`/`libreoffice`；
  - 探测：`--headless --norestore --nofirststartwizard --version`（避免首次安装弹窗）；
  - `metafile_to_png`：写 `anydoc-meta-{pid}-{counter}/input.{wmf|emf}` →
    `--convert-to png --outdir <work>` → 读 `input.png` → 清理。
  - EMF 判定用 byte 40–44 的 `0x464D4520`；其余走 WMF（与 windows_backend 同源）。
- 顶层 `#[cfg(windows)] pub(crate) use windows_backend::metafile_to_png;` / `#[cfg(not(windows))] use unix_backend::metafile_to_png;`。
- `shared/mod.rs` 去掉 `#[cfg(windows)]` 守卫；`shared/assets.rs` 去掉 cfg，让 `image/wmf|image/emf` 在所有平台都走同一条转 PNG 分支。
- 失败策略：找不到 soffice / soffice 退出非 0 / 输出缺失 → `metafile_to_png` 返回 `None` → `assets.rs` 现有 warn + 保留原字节分支接住。

**陷阱**：
- Rust 内联 `mod xxx { ... }` 不能在前面再写一次 `mod xxx;`（双重定义 E0428）。如果需要在外层 `pub(crate) use mod_xxx::item;`，把 `mod xxx { ... }` 写在前面、`use` 写在后面。
- `OnceLock<Option<&'static str>>::get_or_init(...)` 返 `&Option<&'static str>`；要拿到 `Option<&'static str>` 得 `.as_ref().copied()`。
- `OnceLock` 第一次失败会被缓存——soffice 没装就别再探测（每次 1s 冷启动累加）。
